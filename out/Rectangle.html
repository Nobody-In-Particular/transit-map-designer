coordTransformMatrix :DOMMatrixReadOnly

Matrix to transform coordinates before drawing. The inverse is used to transform mouse coordinates to rectangle coordinates when dragging/resizing. This is *not* for transforming between screen and SVG coordinates - that is done automatically anyway. This matrix should transform between some "virtual" coordinates and SVG coordinates.
